# S'entraîner aux échecs — téléchargements

Logiciel d'entraînement aux échecs (ouvertures, tactique, finales, leçons, analyse de vos
parties chess.com / Lichess), en français.

Les fichiers à installer sont dans la page **Releases** (à droite) :

- **Windows** : `Installer-EntrainementEchecs.exe` — fermez le logiciel s'il est ouvert, puis
  lancez l'installateur. Une nouvelle version s'installe par-dessus l'ancienne : vos données
  (dossier Documents\EntrainementEchecs) sont gardées. Si Windows affiche « Windows a protégé
  votre ordinateur », cliquez « Informations complémentaires » puis « Exécuter quand même ».
- **Mac** : `EntrainementEchecs-Mac-AppleSilicon-….zip` pour les Mac récents (puce Apple M1,
  M2, M3…), `EntrainementEchecs-Mac-Intel-….zip` pour les Mac plus anciens. Pour savoir lequel
  vous avez : menu Pomme › « À propos de ce Mac » (« Puce » Apple ou « Processeur » Intel).
  Le mode d'emploi est dans le zip.

Le fichier `versions.json` permet au logiciel d'annoncer une nouvelle version.

Moteur d'analyse : Stockfish (https://stockfishchess.org), logiciel libre sous licence GNU GPL v3.
